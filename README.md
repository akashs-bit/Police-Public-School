# Police-Public-School

# 🏫 School Website

A modern, responsive school website built with HTML, CSS, and JavaScript.

---

## 🔗 Live Demo

[Click here to view the live project 🚀](https://akashs-bit.github.io/Police-Public-School/)

---

## ✨ Features

- 🏠 Home page with welcome banner
- 📅 Events section with upcoming events
- 📚 Courses and departments listing
- 🧑‍🏫 Faculty/staff profiles
- 📞 Contact form with validation
- 📱 Fully responsive on mobile and desktop

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (Vanilla JS)
